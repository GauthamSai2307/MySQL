DAY 3 — SQL & SQL COMMANDS

SQL definition

SQL (Structured Query Language) is a standardized language designed for
managing and manipulating relational databases. It lets users define
what data operation they want without specifying the database engine’s
internal execution steps.

SQL command categories

-   DDL: Defines/modifies database object structure.
-   DML: Inserts, updates and deletes data.
-   DQL: Retrieves data.
-   DCL: Manages permissions/access.
-   TCL: Manages transactions.

DDL commands — definitions and syntax

CREATE: Creates a database object.

    CREATE DATABASE database_name;
    CREATE TABLE table_name (
        column1 datatype,
        column2 datatype
    );

ALTER: Changes an existing object.

    ALTER TABLE table_name ADD column_name datatype;

TRUNCATE: Removes all rows while keeping the table structure.

    TRUNCATE TABLE table_name;

RENAME: Renames a table.

    RENAME TABLE old_name TO new_name;

DML commands — definitions and syntax

INSERT: Adds rows.

    INSERT INTO table_name (column1, column2)
    VALUES (value1, value2);

UPDATE: Modifies existing rows.

    UPDATE table_name
    SET column1 = value1
    WHERE condition;

DELETE: Removes rows.

    DELETE FROM table_name
    WHERE condition;

DQL

SELECT: Retrieves data.

    SELECT column1, column2
    FROM table_name
    WHERE condition;

DCL and TCL

DCL: GRANT, REVOKE

    GRANT SELECT ON database_name.table_name TO 'user'@'host';
    REVOKE SELECT ON database_name.table_name FROM 'user'@'host';

TCL: COMMIT, ROLLBACK, SAVEPOINT

    START TRANSACTION;
    COMMIT;
    ROLLBACK;
    SAVEPOINT savepoint_name;

Interview practice Q&A

Q1. What is SQL?
Answer: SQL is a standardized language used to manage and query
relational databases.

Q2. What is DDL?
Answer: Data Definition Language; it defines or changes database object
structure.

Q3. What is DML?
Answer: Data Manipulation Language; it changes table data using commands
such as INSERT, UPDATE and DELETE.

Q4. What is DQL?
Answer: Data Query Language; SELECT is used to retrieve data.

Q5. What is DCL?
Answer: Data Control Language; GRANT and REVOKE manage access
privileges.

Q6. What is TCL?
Answer: Transaction Control Language; commands such as COMMIT, ROLLBACK
and SAVEPOINT control transactions.
