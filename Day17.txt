DAY 17 — TRIGGERS

Trigger definition

A trigger is a database program that automatically executes in response
to a specified event on a table, such as INSERT, UPDATE or DELETE.

Trigger syntax

    DELIMITER //

    CREATE TRIGGER trigger_name
    BEFORE INSERT ON table_name
    FOR EACH ROW
    BEGIN
        -- statements
    END //

    DELIMITER ;

BEFORE INSERT example from the source

    DELIMITER //

    CREATE TRIGGER before_in_salary
    BEFORE INSERT ON employees
    FOR EACH ROW
    BEGIN
        IF NEW.salary < 20000 THEN
            SIGNAL SQLSTATE '45000'
            SET MESSAGE_TEXT = 'Salary can not be less than 20000';
        END IF;
    END //

    DELIMITER ;

NEW and OLD

For row-level triggers: - NEW.column refers to the new row value. -
OLD.column refers to the existing/old row value.

Typical availability: - INSERT: NEW - UPDATE: OLD and NEW - DELETE: OLD

BEFORE UPDATE example

The source prevents reducing salary:

    DELIMITER //

    CREATE TRIGGER before_salupdate
    BEFORE UPDATE ON employees
    FOR EACH ROW
    BEGIN
        IF NEW.salary < OLD.salary THEN
            SIGNAL SQLSTATE '45000'
            SET MESSAGE_TEXT = 'Salary cannot be reduced';
        END IF;
    END //

    DELIMITER ;

BEFORE DELETE example

The source prevents deletion of IT employees:

    DELIMITER //

    CREATE TRIGGER before_delete
    BEFORE DELETE ON employees
    FOR EACH ROW
    BEGIN
        IF OLD.department = 'IT' THEN
            SIGNAL SQLSTATE '45000'
            SET MESSAGE_TEXT = 'We can''t delete records if the department is IT';
        END IF;
    END //

    DELIMITER ;

Audit trigger concept

The source also creates an Employee_Audit table with fields such as
audit ID, employee ID, action type, old salary, new salary and action
time. This supports an audit-log pattern for INSERT/UPDATE/DELETE
operations.

Schematic

    DML EVENT
     INSERT / UPDATE / DELETE
              |
              v
           TRIGGER
              |
        +-----+-----+
        |           |
     BEFORE       AFTER

Interview practice Q&A

Q1. What is a trigger?
Answer: A trigger automatically executes when a specified INSERT, UPDATE
or DELETE event occurs on a table.

Q2. What is BEFORE INSERT?
Answer: A trigger that executes before a new row is inserted.

Q3. What are OLD and NEW?
Answer: OLD represents the previous row value and NEW represents the
incoming/new row value where supported.

Q4. Prevent salary below 20,000.
Answer: Use a BEFORE INSERT trigger with
IF NEW.salary < 20000 THEN SIGNAL SQLSTATE ....

Q5. Prevent salary reduction.
Answer: Use a BEFORE UPDATE trigger comparing NEW.salary with
OLD.salary.

Q6. What is an audit trigger?
Answer: A trigger that records data-change events in an audit table.
