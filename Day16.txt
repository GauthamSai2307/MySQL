DAY 16 — STORED PROCEDURES

Stored Procedure definition

A stored procedure is a named collection of SQL statements stored in the
database and executed using CALL. The source practices procedures with
and without parameters.

Basic syntax

    DELIMITER //

    CREATE PROCEDURE procedure_name()
    BEGIN
        SQL_statement;
    END //

    DELIMITER ;

Call:

    CALL procedure_name();

Procedure with parameters

    DELIMITER //

    CREATE PROCEDURE GetEmpDetails(IN p_emp_id INT)
    BEGIN
        SELECT *
        FROM employees
        WHERE emp_id = p_emp_id;
    END //

    DELIMITER ;

    CALL GetEmpDetails(105);

Multiple parameters

    DELIMITER //

    CREATE PROCEDURE GetEmpDetailsByDept(
        IN p_emp_id INT,
        IN p_dept VARCHAR(50)
    )
    BEGIN
        SELECT *
        FROM employees
        WHERE emp_id = p_emp_id
          AND department = p_dept;
    END //

    DELIMITER ;

Interview practice Q&A

Q1. What is a stored procedure?
Answer: A named set of SQL statements stored in the database and
executed with CALL.

Q2. Why use DELIMITER?
Answer: Because procedure bodies contain semicolons; changing the client
delimiter lets MySQL receive the complete CREATE PROCEDURE statement.

Q3. How do you pass an input parameter?
Answer: Declare it using IN, for example IN p_emp_id INT.

Q4. Create a procedure to return IT employees.
Answer:

    DELIMITER //
    CREATE PROCEDURE getITEmployees()
    BEGIN
        SELECT *
        FROM employees
        WHERE department = 'IT';
    END //
    DELIMITER ;

Q5. Create a procedure for a salary range.
Answer:

    DELIMITER //
    CREATE PROCEDURE GetEmpDetailsBySalary(
        IN p_min_sal INT,
        IN p_max_sal INT
    )
    BEGIN
        SELECT *
        FROM employees
        WHERE salary > p_min_sal
          AND salary < p_max_sal;
    END //
    DELIMITER ;
